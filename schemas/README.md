# Schemas

This project uses two streaming source datasets:

## Users

Topic:

`sample_data_users`

Contains user attributes used to enrich incoming trading events.

## Stock Trades

Topic:

`sample_data_stock_trades`

Contains continuously generated stock-trading events used by the real-time processing pipeline.

## Enriched Trades

The Flink SQL enrichment combines trading events with user attributes and produces fields including:

- userid
- symbol
- side
- quantity
- price
- account
- regionid
- gender

The exact source schemas are generated by the Confluent Sample Data connectors used during the AI Developer Day workshop.
